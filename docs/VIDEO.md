## Запись видео 1920×1080

1. Откройте страницу в Chrome по `file://`, окно 1920×1080 (F11 или режим устройства 1920×1080), масштаб 100 %. Закройте лишние вкладки и панели.
2. Нажмите «Проектор», если нужна светлая тема для проектора. 3D-окно остаётся тёмным.
3. Запустите запись экрана (OBS или встроенная запись), затем нажмите «● Запись»: это автотур без интерфейса. Панель показа, значок проверки данных и подсказки скрыты; остаётся только подпись главы.
4. Управление в туре: Пробел — пауза, ← / → — главы, Esc — выход. Панель управления появляется, если подвести мышь к нижнему краю окна или нажать H. Скорость ×1,5 в записи не используйте.
5. Для обычного показа вместо «Запись» нажмите «▶ Автотур»: панель управления видна всё время, в ней же кнопка «Без UI».
6. Диктор читает текст из таблицы по таймкодам. Запись голоса удобнее делать отдельно и накладывать на видео: подпись тура рассчитана на ровно 7:00.
